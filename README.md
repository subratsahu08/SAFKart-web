# SAFKart

SAFKart is a local commerce platform connecting customers, local shops, and delivery partners through one connected ecosystem.

This repository contains the SAFKart public launch website, where users can learn about the platform and download the available SAFKart applications.

## 🌐 Live Website

**[SAFKart Web](https://saf-kart-web.vercel.app/)**

## 🌐 SAFKart Ecosystem

The SAFKart platform connects three main roles:

- 🛒 Customer
- 🏪 Shop
- 🛵 Delivery Partner

### Order Journey

Customer places an order  
↓  
Shop receives the order  
↓  
Shop prepares the order  
↓  
Shop marks the order as Ready  
↓  
Delivery Partner accepts the order  
↓  
Delivery Partner picks up the order  
↓  
Delivery Partner delivers the order  
↓  
Customer receives the order

## 📱 SAFKart Applications

### 🛒 Customer App

Customers can:

- Browse products
- Search for products
- Filter products by category
- Add products to cart
- Place orders
- Track orders
- Receive purchases from local shops

### 🏪 Shop App

Shop owners can:

- Receive customer orders
- View order details
- Prepare orders
- Update order status
- Mark orders as Ready
- Hand prepared orders to delivery partners

### 🛵 Delivery App

Delivery partners can:

- View ready orders
- Accept delivery orders
- Verify pickup
- Pick up prepared orders
- Deliver orders to customers
- Complete deliveries
